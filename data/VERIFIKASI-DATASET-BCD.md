## Detail & Rantai Bukti per Dataset

### Dataset B — "Multimodal sensor fusion framework for residential building occupancy detection"
- **Kesimpulan: PUBLIK.** Dataset kunci paper (data 6 rumah) = **HPDmobile**, tersedia publik di Figshare dengan lisensi **CC0**.
- OSTI (host `www.osti.gov`) tidak terjangkau langsung dari host verifikasi ini (timeout semua endpoint, termasuk API; kemungkinan blokir jaringan). Jalur alternatif yang berhasil:
  1. OpenAlex (`api.openalex.org/works/doi:10.1016/j.enbuild.2021.111828`) → `oa_status: green`, 2 lokasi OA: `https://www.osti.gov/biblio/1842869` dan `https://www.osti.gov/biblio/1845893` (OSTI OAI, submittedVersion). Unpaywall mengonfirmasi keduanya.
  2. Wayback Machine snapshot halaman OSTI 1845893 (http://web.archive.org/web/20250426084055/https://www.osti.gov/biblio/1845893, HTTP 200) → abstrak lengkap + link "View Accepted Manuscript (DOE)" → `https://www.osti.gov/servlets/purl/1845893`.
  3. PDF accepted manuscript (9,5 MB) diunduh via Wayback (http://web.archive.org/web/20250209010548/https://www.osti.gov/servlets/purl/1845893, HTTP 200, application/pdf). Isi teks: **tidak ada data availability statement**; bagian 4.2 menyatakan data ketiga = **"Human Presence Detection (HPD) dataset"** — "collected from six different homes for a period of four to eight weeks each", modalitas: temp, RH, light, CO2, TVOC, distance + privacy-preserved images & audio; dirujuk ke data descriptor Nature Scientific Data.
  4. GitHub API: `mhsjacoby/HPDmobile` (200) — "All code related to the collection, processing, and publishing of the HPDmobile residential building occupancy detection dataset", lisensi GPL-3.0; README memuat badge DOI **10.5281/zenodo.4655276**. Repo `tsyong98/STPN` (kode STPN paper B) juga ada.
  5. Data descriptor: **10.1038/s41597-021-01055-x** "A high-fidelity residential building occupancy detection dataset" (Scientific Data, 2021-10-28, Jacoby/Tan/Henze/Sarkar) — OA di nature.com (DOI resolve 200); teks PMC (PMC8553852) memuat **Data Citation**: "HPDmobile… **Figshare**" + statement bahwa kode di GitHub mhsjacoby/HPDmobile.
  6. Figshare API (`api.figshare.com/v2/collections/5364449/articles`, 200): ~60 item publik "HPDmobile H1–H6 …" (Environmental Data, Audio Data, Image Data per hub, Ground Truth, Zone Labels, Dark Image Lists, Metadata). Contoh item diverifikasi: 10.6084/m9.figshare.14368703.v1 (H6 Environmental, `H6_ENVIRONMENTAL.zip` 8.616.752 B, **CC0**, status public), 14368457 (H1, 9.501.019 B), 14368802 (metadata.zip 8.162 B). DOI item resolve 302→200 ke halaman Figshare.
  7. Zenodo 10.5281/zenodo.4655276 = rilis **kode** `mhsjacoby/HPDmobile-v1.0.1-alpha.zip` (2.989.512 B ≈ 2,85 MB), access_right=open, license "other-open".
- Dataset lain yang dipakai paper (bonus): ECO (ETH) & UCI Building Occupancy Detection (publik).

### Dataset C — "Fusion of Environmental Sensors for Occupancy Detection in a Real Construction Site"
- **Kesimpulan: TIDAK PUBLIK** (restricted) — hipotesis Zenodo 8203278 **TERKONFIRMASI** sebagai dataset paper, tetapi aksesnya dibatasi.
- MDPI (`www.mdpi.com`) mengembalikan HTTP 403 dari host ini (blokir bot). Jalur alternatif berhasil: artikel ada di PMC (**PMC10708732**, `pmc.ncbi.nlm.nih.gov/articles/PMC10708732/`, HTTP 200). Teks artikel:
  - Bagian 2.3 Dataset Description: "The dataset used in this paper can be found online (Released on December 2023, **http://doi.org/10.5281/zenodo.8203278**). It consists of environmental sensor measurements from the construction of a 27-story office building… sound level, temperature, relative humidity, dust, and air pressure… February 2021 to May 2022."
  - Data Availability Statement: "The dataset used for this paper is available in the Zenodo repository. ( http://doi.org/10.5281/zenodo.8203278 )."
- Zenodo API (`zenodo.org/api/records/8203278`, 200): "Environmental sensor data for occupancy detection", publikasi 2023-08-01, proyek EU ASHVIN, kreator: Athina Tsanousa, Evangelos Bektsis, Chrysoula Moschou (ITI-CERTH) — **identik dengan penulis paper**. **`access_right: restricted`**, `files: []`, license: none. Halaman HTML menampilkan "Restricted / request access", tanpa nama file. Concept DOI 10.5281/zenodo.8203277 redirect ke record yang sama (hanya satu versi). Endpoint files → 403.
- DOI 10.5281/zenodo.8203278 resolve HTTP 200 → `https://zenodo.org/records/8203278`.
- Catatan penting: paper menyatakan "The data … are provided as a public dataset", namun praktiknya record Zenodo di-restricted — perlu request access ke penulis.

### Dataset D — "Multimodal feature fusion and ensemble learning for non-intrusive occupancy monitoring using smart meters"
- **Kesimpulan: dataset = ECO (publik), bukan UK-DALE/REFIT.**
- OpenAlex (`api.openalex.org/works/doi:10.1016/j.buildenv.2025.112635`, 200) — abstrak lengkap (abstract_inverted_index): "…achieve a state-of-the-art non-intrusive occupancy classification performance of 91.5 % accuracy … by an ensemble of fine-tuned classifiers on the **electricity consumption & occupancy (ECO) dataset**."
- Status OA paper: hybrid; Crossref license `vor` = **CC BY 4.0**; DOI resolve 200 → linkinghub.elsevier.com/retrieve/pii/S0360132325001179. Salinan accepted manuscript publik di Figshare/Manara (Qatar National Library): Figshare API `api.figshare.com/v2/articles/30233791` (200) — `10.1016_j.buildenv.2025.112635.pdf` 4.439.468 B + `supp_1-s2.0-S0360132325001179-mmc1.docx` 299.478 B, **CC BY 4.0**, status public. (File download `ndownloader.figshare.com` mengembalikan 202/403 dari host ini, tapi metadata API & halaman artikel valid.)
- ECO dataset (ETH Zurich, Kleiminger, Beckel, Santini):
  - Halaman resmi `https://vs.inf.ethz.ch/res/show.html?what=eco-data` — HTTP 200; isi: "We make the ECO data set available to the research community. You may directly access the data set, but we always like to receive a short description on what you plan to do with the data via e-mail to Wilhelm Kleiminger." 6 rumah tangga Swiss, 8 bulan, data 1 Hz agregat + plug-level + ground truth occupancy.
  - Link file langsung lama (`project/eco-data-files/01_occupancy_csv.zip` dsb.) → **404** (mati).
  - ETH Data Archive (`app.data-archive.ethz.ch/delivery/DeliveryManagerServlet?dps_pid=IE594964`) — 200, tapi memerlukan login (dashboard; kredensial via Kleiminger).
  - ETH Research Collection (DSpace 7 API): item "ECO Data Set" handle `20.500.11850/185963`, DOI 10.5905/ethz-1007-35, **ethz.availability: "Metadata only"** — tidak ada bitstream data.
- Konsekuensi untuk penulisan paper: ECO dapat dikutip sebagai dataset publik dengan URL halaman resmi; untuk unduhan aktual perlu kontak penjaga data.

## Kendala & Catatan Metodologis
- `web_search`/`web_extract` tidak dipakai (backend tidak tersedia). Semua verifikasi via HTTP langsung.
- OSTI dan MDPI memblokir host ini (timeout / 403) → digantikan oleh Wayback Machine (OSTI) dan PMC (MDPI). Situs yang sepenuhnya 403 (ScienceDirect) tidak dipaksakan.
- Zenodo API rawan 403 → jeda 15–20 detik antar panggilan; berhasil untuk record 8203278, 8203277, 4655276, 20548374.
- Gambar/audio HPDmobile berukuran besar; hanya ukuran file yang diverifikasi via API, bukan isi unduhan penuh.
