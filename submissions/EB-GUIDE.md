## Persyaratan Kunci

| Item | Aturan |
|---|---|
| Jenis paper | Original paper: **maks. 20 halaman double-line-spaced** termasuk tabel & gambar; review/short comm: 10 halaman |
| Format | **Your Paper Your Way** — submit Word/PDF tunggal utk review; format ketat HANYA saat revisi/acceptance |
| Struktur wajib | Abstract, Keywords, Introduction, Materials and Methods, Results, Conclusions, (References) |
| Abstract | **≤ 200 kata**, faktual (tujuan, hasil utama, kesimpulan), stand-alone (hindari referensi; non-standard abbreviation dihindari) |
| Highlights | 3-5 bullet, **maks. 85 karakter per bullet** (spasi termasuk), file terpisah "Highlights" |
| Keywords | wajib (jumlah bebas; umumnya 4-6) |
| Reference style | Elsevier terapkan otomatis di proof stage (numeric); data missing ditandai saat proof |
| Title page | Essential title page information (judul, penulis, afiliasi, corresponding author) |
| Deklarasi | Ethics, competing interest, **generative AI declaration**, submission declaration, author contributions, funding, open access |
| Gambar | Semua figures + caption; color indication; resolusi sesuai ketentuan artwork |
| Tabel | Judul + deskripsi + footnote |
| Data | Research data statement (wajib; repo publik kami memenuhi) |

## Catatan untuk naskah kami

- Abstrak ≤200 kata — naskah v1 (writer) target 250 → perlu dipangkas ke ≤200 saat format
- Highlights 3-5 bullet ≤85 char — perlu dibuat
- Original paper ≤20 halaman double-spaced → naskah 6.000-7.500 kata + 6 tabel + 4 gambar ≈ aman
- "Your Paper Your Way" → v1 markdown cukup utk review; konversi template saat revisi
- Generative AI declaration: WAJIB diisi (penulisan dibantu AI) — siapkan template pernyataan
- Research Data: repo GitHub 15FST015/iot-occupancy-multimodal + Zenodo dataset (CC-BY-4.0)
